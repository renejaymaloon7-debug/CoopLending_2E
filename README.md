Open NetBeans, IntelliJ IDEA, Eclipse, or another Java IDE.

Create a new Java Project.
Create a Java class named Main.
Copy and paste the given Java code into the Main class.
Make sure the file is saved as Main.java.
Click Run or press the Run button.

The COOPFUND SYSTEM menu will appear in the console.
Enter a number from 1 to 8 to select an option.
Start with Option 1 – Register Member & Share Capital.
Enter the required member information.
Select Option 2 – File Loan Application to enter the loan details.
Select Option 3 – Evaluate Loan Eligibility to check if the member qualifies.
Continue with the available options for interest, payment, overdue accounts, and the summary report.
Select Option 8 – Exit System when you are finished.
